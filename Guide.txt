Pacman for macOS - Installation & Uninstallation Guide
======================================================

This guide explains how to perform a fresh rootless installation from source (supporting both Apple Silicon `darwin_arm64` and Intel `darwin_x86_64`), configure your shells (`fish` and `zsh`), and manage packages without `sudo`.

------------------------------------------------------
0. ONE-LINE / AUTOMATED INSTALLER
------------------------------------------------------

From a local clone:
  ./install.sh

Or via curl:
  curl -fsSL https://raw.githubusercontent.com/revanthnemtoor/project_pacman/main/install.sh | bash

------------------------------------------------------
1. MANUAL INSTALLATION (From ./pacman Source)
------------------------------------------------------

# 1. Create /opt/pacman owned by your user (no sudo needed afterwards)
sudo mkdir -p /opt/pacman
sudo chown -R $(whoami):$(id -gn) /opt/pacman

# 2. Compile patched pacman from ./pacman inside this repository
cd pacman
BREW_PREFIX="$(brew --prefix 2>/dev/null || echo '/opt/homebrew')"
export PKG_CONFIG_PATH="/opt/homebrew/lib/pkgconfig:/usr/local/lib/pkgconfig:/opt/local/lib/pkgconfig"
export CFLAGS="-I/opt/homebrew/include -I/usr/local/include -I/opt/local/include"
export LDFLAGS="-L/opt/homebrew/lib -L/usr/local/lib -L/opt/local/lib -liconv -lintl"
rm -rf build
meson setup build \
    --prefix=/opt/pacman \
    --sysconfdir=/opt/pacman/etc \
    --localstatedir=/opt/pacman/var \
    -Dpkg-ext=.pkg.tar.zst \
    -Dcrypto=openssl \
    -Ddoc=disabled \
    -Dgpgme=disabled
ninja -C build install

# 3. Configure /opt/pacman/etc/pacman.conf (auto-detects darwin_arm64 & darwin_x86_64)
cp ../configs/pacman.conf /opt/pacman/etc/pacman.conf

# 4. Add /opt/pacman/bin to PATH (Fish & Zsh)
fish -c "fish_add_path -g /opt/pacman/bin"
echo 'export PATH="/opt/pacman/bin:$PATH"' >> ~/.zshrc

# 5. Sync Databases and Query / Install Packages (No sudo required!)
pacman -Sy
pacman -Sl
pacman -S <package_name>

------------------------------------------------------
2. COMPLETE UNINSTALLATION
------------------------------------------------------

If you wish to remove pacman and all installed packages entirely from your system:

sudo rm -rf /opt/pacman
