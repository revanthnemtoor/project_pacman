Pacman for macOS

A native, rootless port of Arch Linux's Pacman (v7.1.0) and libalpm (v16.0) package manager to macOS (Darwin).

Pacman v7.1.0 libalpm v16.0 macOS Darwin darwin_arm64 / darwin_x86_64 100% Source-Built Rootless (/opt/pacman) GPL-2.0-or-later

Every package in the core repository is built natively from upstream source releases with Apple Clang and Ninja. There are zero Homebrew runtime dependencies or bottles. All binaries and shared libraries are genuine Darwin Mach-O executables, ad-hoc codesigned for Gatekeeper compatibility, and run in a fully user-owned /opt/pacman hierarchy.

Quick Start Installation

Universal One-Line Installer
bash -c "$(curl -fsSL https://raw.githubusercontent.com/revanthnemtoor/project_pacman/main/install.sh)"

Alternative Install Methods

From a local git clone:

git clone https://github.com/revanthnemtoor/project_pacman.git
cd project_pacman
./install.sh

Non-interactive / CI automated mode (skips prompts, default Top Priority PATH):

curl -fsSL https://raw.githubusercontent.com/revanthnemtoor/project_pacman/main/install.sh | bash -s -- -y

Architecture Support

Pacman for macOS supports both major modern Apple Mac CPU architectures:

Architecture Platform Identifier macOS Minimum Status
Apple Silicon darwin_arm64 macOS 12+ (M1 / M2 / M3 / M4) Fully Supported
Intel x86_64 darwin_x86_64 macOS 12+ (64-bit Intel Macs) Fully Supported

Interactive Installer Options

Upon launching, the installer detects your Mac model and architecture, displays a splash screen, and prompts you through two simple configuration choices:

1. Confirmation Prompt

Choose whether to proceed with installation ([1] Continue) or abort safely ([2] Cancel / Exit) without modifying any files.

2. Shell PATH Priority

Top Priority (Default): Prepends /opt/pacman/bin so modern GNU tools supersede old macOS defaults.
Add to PATH: Appends to PATH as fallback.
Skip: Leaves shell profiles untouched.

Pacman Command Reference

Pacman commands on macOS function identically to Arch Linux:

# 1. Update package databases and upgrade all installed packages
pacman -Syu

# 2. Re-synchronize and permit version alignment / downgrades
pacman -Syuu

# 3. Install packages
pacman -S bash coreutils jq nano

# 4. Search packages in remote repositories
pacman -Ss python

# 5. Show detailed information about a package
pacman -Si openssl

# 6. List installed packages
pacman -Q

# 7. Remove a package
pacman -R package_name

# 8. Query which package provides a specific library or file
pacman -Fy
pacman -F libalpm.dylib
No sudo required!
Because /opt/pacman is owned by your user, you run pacman directly without sudo.

Configuration (pacman.conf)

The primary configuration file resides at /opt/pacman/etc/pacman.conf:

[options]
RootDir     = /
DBPath      = /opt/pacman/var/lib/pacman/
CacheDir    = /opt/pacman/var/cache/pacman/pkg/
LogFile     = /opt/pacman/var/log/pacman.log
GPGDir      = /opt/pacman/etc/pacman.d/gnupg/
HookDir     = /opt/pacman/etc/pacman.d/hooks/
HoldPkg     = pacman
Architecture = auto any

Color
CheckSpace
ParallelDownloads = 5
XferCommand = /usr/bin/curl -L -C - -f -o %o %u

SigLevel    = Optional TrustAll
LocalFileSigLevel = Optional
RemoteFileSigLevel = Optional

[core]
SigLevel = Optional TrustAll
Server = https://raw.githubusercontent.com/revanthnemtoor/project_pacman/main/core
Server = https://revanthnemtoor.github.io/project_pacman/core

[extra]
SigLevel = Optional TrustAll
Server = https://raw.githubusercontent.com/revanthnemtoor/project_pacman/main/extra
Server = https://revanthnemtoor.github.io/project_pacman/extra

Security & Integrity

SHA-256 Checksums

Every package archive is verified against SHA-256 digests in core.db and extra.db before unpacking. Tampered files are rejected.

Ad-Hoc Mach-O Code Signing

Every binary executable and .dylib is signed using macOS codesign --sign -, satisfying Gatekeeper and runtime requirements.
